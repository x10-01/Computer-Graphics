# 7. Shader Program 创建、链接与验证

## 7.1 创建 Program

在 `main()` 中，GLEW 初始化成功后、进入 `while` 渲染循环前创建 Program：

``` cpp
GLuint shaderProgram = glCreateProgram();
CreateShaderProgram(shaderProgram);
```

老师强调这两行应位于 GLEW 初始化之后、Render Loop 之前。不要把 Shader
创建与链接流程每帧重复执行。

## 7.2 附加两个 Shader

在 `CreateShaderProgram()` 内，Vertex Shader 和 Fragment Shader
分别编译成功后：

``` cpp
glAttachShader(shaderProgram, vertexShader);
glAttachShader(shaderProgram, fragmentShader);
```

这一步把两个 Shader 对象附加到同一个 Program 对象中。

## 7.3 链接 Program

``` cpp
glLinkProgram(shaderProgram);
glGetProgramiv(shaderProgram, GL_LINK_STATUS, &success);
```

`glLinkProgram()` 请求链接；`GL_LINK_STATUS` 用于查询链接是否成功。

## 7.4 链接失败时读取 Program 日志

``` cpp
if (!success)
{
    GLchar infoLog[1024];
    glGetProgramInfoLog(shaderProgram, 1024, NULL, infoLog);
    std::cout
        << "ERROR::PROGRAM::LINK_FAIL\n"
        << infoLog << std::endl;
    exit(-1);
}
```

这里必须调用 `glGetProgramInfoLog()`，因为要查询的是 Program
的链接日志，不是单个 Shader 的编译日志。

## 7.5 验证与删除 Shader 对象

课堂截图还包含 `glValidateProgram()` 与 `GL_VALIDATE_STATUS`
的检查分支，以及链接完成后：

``` cpp
glDeleteShader(vertexShader);
glDeleteShader(fragmentShader);
```

链接成功后，已经附加并链接完成的 Program 不再依赖这两个 Shader
对象继续保留，因此可以删除 Shader 对象。Program
本身仍然保留供后续绘制使用。

课堂代码中的平台条件编译块按老师给出的版本记录。若后续需要核对
`#ifdef __WIN64`
是否与当前编译器定义一致，应先向老师确认，不要为了"优化"擅自替换老师的代码结构。

## 7.6 Shader Program 在整体流程中的位置

``` text
glfwInit / 创建窗口 / 当前 Context
                ↓
             glewInit
                ↓
       glCreateProgram()
                ↓
       CreateShaderProgram()
                ↓
  编译 VS、编译 FS、Attach、Link
                ↓
           Render Loop
                ↓
   glUseProgram(shaderProgram)
```

`CreateShaderProgram()` 是一次性准备渲染程序的函数；`RenderObject()`
在实际绘制时调用 `glUseProgram()` 让对应 Program 生效。
