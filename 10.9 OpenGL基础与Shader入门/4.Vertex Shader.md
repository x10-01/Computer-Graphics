# 4. Vertex Shader

## 4.1 `#version 330 core`

``` glsl
#version 330 core
```

声明 Shader 使用 GLSL 3.30，并采用 Core Profile
对应的语言规则。它与程序创建时设置的 OpenGL 版本及 Profile 相互对应。

## 4.2 `layout (location = 0)`

``` glsl
layout (location = 0) in vec3 position;
```

`location = 0` 指定该输入变量对应的顶点属性索引 0。它需要与 C++ 端
`glVertexAttribPointer()` 使用的第一个参数一致。

## 4.3 `in vec3 position`

-   `in`：表示这是输入到 Vertex Shader 的顶点属性。
-   `vec3`：由三个分量组成的向量。
-   `position`：变量名，由代码编写者命名。

本节三个顶点的数据每个都包含 `x、y、z` 三个坐标分量，因此使用 `vec3`。

## 4.4 Vertex Shader 输入从哪里来

本节的输入数据来自 VBO 中的顶点数组。VAO
记录属性索引、每个属性有几个分量、数据类型、步长和偏移量等信息。绘制时，OpenGL
根据这些配置向 Vertex Shader 提供 `position`。

## 4.5 `gl_Position`

``` glsl
gl_Position = vec4(position, 1.0f);
```

`gl_Position` 是 Vertex Shader
的内置输出变量，用于输出顶点位置。其类型是四分量向量 `vec4`。

## 4.6 为什么输入 `vec3`，输出 `vec4`

输入顶点数组目前存储三个坐标分量：

``` text
x, y, z
```

而 `gl_Position` 使用四分量齐次坐标：

``` text
x, y, z, w
```

所以代码使用 `vec4(position, 1.0f)`，把三维位置与第四个分量 `w = 1.0`
组合起来。

这不是要求所有输入都必须是 `vec3`，而是当前数据布局采用三维坐标，同时
OpenGL 的 `gl_Position` 输出需要 `vec4`。

## 4.7 当前三角形的坐标

``` cpp
GLfloat vertices[] =
{
    -0.5f, -0.5f, 0.0f,
     0.0f,  0.5f, 0.0f,
     0.5f, -0.5f, 0.0f
};
```

三个顶点分别是：

  顶点        x      y     z
  ------ ------ ------ -----
  0        -0.5   -0.5   0.0
  1         0.0    0.5   0.0
  2         0.5   -0.5   0.0

所有 `z` 都为
0，所以当前三角形位于一个平面内。坐标处于当前视口映射所用的标准范围附近，因此可以在窗口中看到三角形。

## 4.8 容易混淆的概念

-   `position`：用户定义的输入变量。
-   `gl_Position`：GLSL 内置的顶点位置输出变量。
-   `layout(location = 0)`：Shader 端的属性索引声明。
-   `glVertexAttribPointer(0, ...)`：C++/OpenGL
    端配置相同索引的顶点属性读取方式。

两端索引必须对应。
