# 9. `glVertexAttribPointer()` 参数拆解

> 本节是老师明确指出的重点，也是第一次作业可能要求现场修改并解释的知识点。

## 9.1 课堂代码

``` cpp
glVertexAttribPointer(
    0, 3, GL_FLOAT, GL_FALSE,
    3 * sizeof(GLfloat), (GLvoid*)0
);
```

## 9.2 六个参数

  ---------------------------------------------------------------------------------------------
  参数                    含义                                     与当前代码的对应关系
  ----------------------- ---------------------------------------- ----------------------------
  `0`                     顶点属性索引                             对应 `layout (location = 0)`

  `3`                     每个属性包含的分量数                     对应 `in vec3 position`，即
                                                                   x、y、z

  `GL_FLOAT`              每个分量的数据类型                       当前数组元素是 `GLfloat`

  `GL_FALSE`              是否将非浮点数据归一化到浮点范围         当前不进行归一化

  `3 * sizeof(GLfloat)`   相邻两个顶点属性起始位置之间的字节步长   每个顶点占 3 个浮点数

  `(GLvoid*)0`            当前顶点属性在绑定缓冲区中的起始偏移量   从缓冲区第一个数据开始读取
  ---------------------------------------------------------------------------------------------

## 9.3 用当前数组理解步长

当前数组的布局是：

``` text
索引：    0       1       2       3       4       5       6       7       8
数据：   x0      y0      z0      x1      y1      z1      x2      y2      z2
          └──── 顶点 0 ────┘      └──── 顶点 1 ────┘      └──── 顶点 2 ────┘
```

每个顶点包含三个 `GLfloat`，因此属性起始位置之间的间隔为：

``` cpp
3 * sizeof(GLfloat)
```

在常见平台上 `sizeof(GLfloat)` 为 4 字节，所以当前步长是 12
字节。应记住表达式的含义，而不是只死记数值。

## 9.4 为什么偏移量是 0

``` cpp
(GLvoid*)0
```

表示当前属性从绑定的 VBO
数据起始位置开始读取。当前数组开头就是第一个顶点的 x 坐标，所以偏移量为
0。

## 9.5 与 Shader 的对应关系

Shader 端：

``` glsl
layout (location = 0) in vec3 position;
```

C++ 端：

``` cpp
glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE,
                      3 * sizeof(GLfloat), (GLvoid*)0);
glEnableVertexAttribArray(0);
```

二者需要相互对应：

-   属性索引 0 对应 `location = 0`。
-   三个分量对应 `vec3`。
-   数据类型对应 `GLfloat`。
-   步长与偏移量对应 `vertices[]` 的实际排列方式。

## 9.6 作业现场解释模板

如果老师要求修改参数，应按以下顺序回答：

1.  **改了哪个参数？**
2.  **它控制什么？**
3.  **它与 Shader 输入或 `vertices[]` 的哪一部分对应？**
4.  **改变后，数据读取方式或绘制结果会有什么变化？**

不能只说"这是固定写法"。每个参数都对应实际的数据布局。
