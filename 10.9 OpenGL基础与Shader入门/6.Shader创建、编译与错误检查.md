# 6. Shader 创建、编译与错误检查

## 6.1 创建 Shader：`glCreateShader()`

``` cpp
GLuint vertexShader = glCreateShader(GL_VERTEX_SHADER);
```

创建一个 Vertex Shader 对象。Fragment Shader 对应：

``` cpp
GLuint fragmentShader = glCreateShader(GL_FRAGMENT_SHADER);
```

这一步创建 Shader 对象，还没有完成源码提交或编译。

## 6.2 提交源码：`glShaderSource()`

``` cpp
glShaderSource(vertexShader, 1, &vertexShaderSource, NULL);
```

把 C++ 中保存的 Shader 源码字符串提交给指定 Shader 对象。

参数含义：

1.  `vertexShader`：目标 Shader 对象。
2.  `1`：源码字符串数量。
3.  `&vertexShaderSource`：源码字符串指针的地址。
4.  `NULL`：没有额外指定每段字符串的长度，OpenGL 按字符串结束符判断。

## 6.3 编译：`glCompileShader()`

``` cpp
glCompileShader(vertexShader);
```

请求 OpenGL 编译指定
Shader。调用编译函数并不代表编译一定成功，因此必须检查状态。

## 6.4 查询编译状态：`glGetShaderiv()`

``` cpp
GLint success;
glGetShaderiv(vertexShader, GL_COMPILE_STATUS, &success);
```

-   `GL_COMPILE_STATUS`：查询 Shader 编译是否成功。
-   `success`：接收查询结果。
-   `&success`：把变量地址传入，以便 OpenGL 写入结果。

## 6.5 失败时读取日志

``` cpp
if (!success)
{
    GLchar infoLog[1024];
    glGetShaderInfoLog(vertexShader, 1024, NULL, infoLog);
    std::cout
        << "ERROR::SHADER::VERTEX::COMPILATION_FAIL\n"
        << infoLog << std::endl;
    exit(-1);
}
```

-   `GLchar infoLog[1024]`：准备接收错误日志的字符数组。
-   `glGetShaderInfoLog()`：读取 Shader 编译日志。
-   `std::cout`：把错误类别与具体日志输出到控制台。
-   `exit(-1)`：编译失败时终止程序，避免继续使用无效的 Shader。

Fragment Shader 也需要对应的编译状态检查和日志读取。

## 6.6 `success` 变量只能在同一作用域内重复使用，不能重复定义

本次遇到编译错误：

``` text
C2086: “GLint success”: 重定义
```

原因是 `CreateShaderProgram()` 中已经声明过：

``` cpp
GLint success;
```

如果在同一个函数作用域里，处理 Fragment Shader 时又写一次：

``` cpp
GLint success;
```

就会产生重定义错误。应保留一次声明，并让 Vertex Shader、Fragment
Shader、Program Link 等状态查询复用这个变量。

注意：复用变量不等于复用错误日志内容；每次查询仍要检查对应对象与对应状态。

## 6.7 两类日志函数不能混用

-   Shader 编译失败：`glGetShaderInfoLog(shader, ...)`
-   Shader Program 链接失败：`glGetProgramInfoLog(program, ...)`

前者接收 Shader 对象，后者接收 Program
对象。即使函数名相似，也不能只改日志文字而忘记改 API 函数本身。

本次曾出现链接失败分支仍调用 `glGetShaderInfoLog()`
的情况，之后发现并改为 `glGetProgramInfoLog()`。详见
[课堂错误记录](./12.课堂错误记录与排查.md)。

## 6.8 编译阶段与链接阶段的区别

-   Shader 编译：检查单个 Vertex Shader 或 Fragment Shader
    的源码能否编译。
-   Program 链接：把附加到同一个 Program 的 Shader
    阶段连接成可使用的程序。

因此，单个 Shader 编译成功，不代表 Program
一定链接成功；两个阶段都要检查。
