## 13.2 必须掌握的代码顺序

``` text
初始化 GLFW
→ 设置版本与 Profile
→ 创建窗口
→ 设置当前 Context
→ 初始化 GLEW
→ CreateVertexBuffer()
→ glCreateProgram()
→ CreateShaderProgram(shaderProgram)
→ while Render Loop
    → SetViewport(window)
    → glClearColor()
    → glClear()
    → RenderObject(shaderProgram, VAO)
    → glfwSwapBuffers()
    → glfwPollEvents()
→ glfwTerminate()
```

以上顺序按课堂当前代码整理。若老师后续修改顺序，以老师的最新要求为准。
