# 8. VAO 与 VBO 顶点数据管理

## 8.1 VAO 与 VBO 的含义

-   **VAO：Vertex Array Object，顶点数组对象。**
-   **VBO：Vertex Buffer Object，顶点缓冲对象。**

`VAO` 和 `VBO` 是 OpenGL
中常用的缩写名称。代码中的变量名可以自行选择，但应保持清晰、一致，并与图形相关对象对应。

## 8.2 当前顶点数据

``` cpp
GLfloat vertices[] =
{
    -0.5f, -0.5f, 0.0f,
     0.0f,  0.5f, 0.0f,
     0.5f, -0.5f, 0.0f
};
```

数据按顺序存储，每三个 `GLfloat` 组成一个顶点的 `x、y、z` 坐标。当前共 3
个顶点、9 个浮点数。

## 8.3 创建对象

``` cpp
glGenVertexArrays(1, &VAO);
glGenBuffers(1, &VBO);
```

这两条调用分别生成 VAO 与 VBO 对象名称。

## 8.4 绑定对象

``` cpp
glBindVertexArray(VAO);
glBindBuffer(GL_ARRAY_BUFFER, VBO);
```

-   绑定 VAO，开始配置这个 VAO 对应的顶点属性状态。
-   将 VBO 绑定到 `GL_ARRAY_BUFFER`
    目标，供接下来的数据上传与属性配置使用。

## 8.5 把顶点数据交给缓冲区

``` cpp
glBufferData(
    GL_ARRAY_BUFFER,
    sizeof(vertices),
    vertices,
    GL_STATIC_DRAW
);
```

参数含义：

-   `GL_ARRAY_BUFFER`：当前操作的缓冲区目标。
-   `sizeof(vertices)`：整个数组占用的字节数。
-   `vertices`：源数据地址。
-   `GL_STATIC_DRAW`：提示数据将由应用程序提供，预计用于绘制且不会频繁修改。

VBO 保存实际顶点数据；VAO 记录如何读取这些数据。两者职责不同。

## 8.6 配置顶点属性并启用

``` cpp
glVertexAttribPointer(
    0, 3, GL_FLOAT, GL_FALSE,
    3 * sizeof(GLfloat), (GLvoid*)0
);
glEnableVertexAttribArray(0);
```

`glVertexAttribPointer()`
定义属性读取规则；`glEnableVertexAttribArray(0)` 启用索引 0
的顶点属性数组。

这一组配置必须与 Vertex Shader 的：

``` glsl
layout (location = 0) in vec3 position;
```

对应。详细参数解释见 [glVertexAttribPointer
参数拆解](./9.glVertexAttribPointer参数拆解.md)。

## 8.7 解除绑定

``` cpp
glBindBuffer(GL_ARRAY_BUFFER, 0);
glBindVertexArray(0);
```

解除当前绑定，避免后续代码无意中继续修改当前对象状态。按课堂顺序，在完成属性配置后先解除
`GL_ARRAY_BUFFER` 绑定，再解除 VAO 绑定。

``` cpp
GLuint VAO, VBO;

static void CreateVertexBuffer()

```
