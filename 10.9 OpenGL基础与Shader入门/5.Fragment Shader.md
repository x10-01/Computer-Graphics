# 5. Fragment Shader

## 5.1 Fragment Shader 的作用

Fragment Shader 在光栅化之后处理产生的片段。本节的 Shader
不进行纹理采样或复杂计算，而是为每个被处理的片段输出固定颜色。

## 5.2 `out vec4 FragColor`

``` glsl
out vec4 FragColor;
```

-   `out`：声明 Shader 的输出变量。
-   `vec4`：输出包含四个分量。
-   `FragColor`：变量名，由程序编写者命名。

它是当前 Fragment Shader 的颜色输出变量。

## 5.3 输出红色

``` glsl
FragColor = vec4(1.0f, 0.0f, 0.0f, 1.0f);
```

四个分量依次表示 R、G、B、A：

``` text
R = 1.0
G = 0.0
B = 0.0
A = 1.0
```

因此输出为不透明红色。窗口背景颜色由 `glClearColor()` 设置，三角形颜色由
Fragment Shader 输出，两者不是同一个设置位置。

## 5.4 Fragment 与 Pixel 的基本区别

-   **Fragment（片段）：**
    光栅化阶段生成、等待后续处理的候选样本，可能带有位置、插值属性等信息。
-   **Pixel（像素）：** 图像或帧缓冲区中的像素位置/存储单元。

初学阶段可以把 Fragment Shader
理解为"为三角形覆盖区域中的片段计算颜色"，但不要把 Fragment
与最终屏幕像素完全等同；多重采样等机制下，两者不一定是一对一关系。
