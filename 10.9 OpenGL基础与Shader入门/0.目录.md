程序初始化继续推进到顶点数据管理与实际绘制，最终运行程序并显示一个红色三角形。

5.  `glVertexAttribPointer()` 的每个参数如何对应 Shader 输入。
6.  `RenderObject()` 如何调用 Shader Program 和 VAO 绘制三角形。

## 三、本节课的整体流程

``` text
GLFW 初始化
  ↓
设置 OpenGL 版本与 Core Profile
  ↓
创建窗口和 OpenGL Context
  ↓
使 Context 成为当前上下文
  ↓
初始化 GLEW
  ↓
创建 VAO/VBO 并配置顶点属性 ───────┐
  ↓                               │
创建、编译 Vertex/Fragment Shader  │
  ↓                               │
附加 Shader 并链接 Shader Program │
  └──────────────┬────────────────┘
                 ↓
             Render Loop
                 ↓
       设置 Viewport、清屏
                 ↓
      RenderObject(shaderProgram, VAO)
                 ↓
           glDrawArrays()
                 ↓
        glfwSwapBuffers()
                 ↓
        glfwPollEvents()
```

## 四、本节课的结构性认识

老师把程序中的工作概括为两条线：

-   **渲染线：** `CreateShaderProgram()`，负责创建和准备 Shader
    Program。
-   **顶点线：** `CreateVertexBuffer()`，负责准备顶点数据以及 VAO/VBO
    配置。

两条线在 `RenderObject(shaderProgram, VAO)` 中汇合：绘制时使用 Shader
Program，并绑定对应 VAO，随后发出绘制命令。
