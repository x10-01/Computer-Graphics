## 3. 上传到 GitHub 的建议

1.  解压本 ZIP。
2.  将整个 `Computer_Graphics_Course_Notes_Update_2026-11-11`
    文件夹复制到现有 `Computer-Graphics` 仓库根目录。
3.  保留现有 `9.11`、`9.18`、`10.9` 原目录，不要用本包覆盖原目录。
4.  将本包作为增量更新提交；后续可根据"修订操作清单"把更正内容合并回原有笔记。
5.  `reference_source_snapshot`
    是本次核验所用的**原样参考副本**，不是房子作业答案，也不是让你覆盖课堂项目的代码。
6.  `evidence` 中的截图用于追溯配置和数据布局。不要把
    `.exe`、`.pdb`、`.vs` 缓存或整套第三方库复制进本笔记更新包。

## 4. 重要纪律

-   本包记录课堂知识、原始代码状态、配置证据与待确认事项。
-   不生成房子作业的可直接提交程序，不替代学生本人编程。
-   原课堂项目必须保留，作为课堂小测试和现场考核基线。
-   房子作业应新建独立项目，并按老师要求使用最新课堂版本及 `Shader` 类。
-   以后每次课堂结束，先保存原始代码和截图，再更新课堂记录；不能把推断写成老师要求。
