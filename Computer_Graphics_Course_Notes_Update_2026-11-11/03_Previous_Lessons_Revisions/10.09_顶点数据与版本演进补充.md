# 10 月 9 日课程笔记补充：VAO/VBO、顶点属性与后续版本演进

> 10.9 原始笔记已经详细记录红色三角形、Shader
> Program、VAO/VBO、`glVertexAttribPointer()` 和 Render
> Loop。本文件不覆盖原始记录，而是补上 11.6 与 11.11
> 的版本变化，并更新作业预告。

## 1. 10.9 原始版本应继续保留

10.9 的课堂状态：

-   `CreateShaderProgram()` 负责准备 Shader Program。
-   `CreateVertexBuffer()` 负责准备顶点数组、VBO、VAO 和顶点属性。
-   `RenderObject(shaderProgram, VAO)` 在绘制时使用 Program、绑定 VAO
    并调用 `glDrawArrays()`。
-   顶点数组每个顶点只有 `x、y、z` 三个位置分量。
-   `glVertexAttribPointer()` 的 stride 为 `3 * sizeof(GLfloat)`，offset
    为 0。
-   运行结果为红色三角形。

这些是 10.9 当时的课程事实，不能用后续版本覆盖。

## 2. 11.6 的 Shader 管理方式变化

后续课堂将原先在 `main.cpp` 中定义 Shader 字符串并调用
`CreateShaderProgram()` 的方式，改为：

-   在 `shader.h` 中定义 `Shader` 类。
-   通过构造函数读取外部 `res/shaders/core.vs` 与
    `res/shaders/core.fs`。
-   构造函数内部完成 Shader 创建、编译、附加和 Program 链接。
-   通过 `shader.UseProgram()` 启用 Program。
-   `RenderObject()` 改为接收 `Shader&` 和 VAO。

这属于程序组织方式的演进。10.9
笔记中的旧版本代码仍然有复习价值，尤其是理解 Shader 编译、Program
链接的底层过程。

## 3. 11.11 的顶点数据变化

10.9：

``` text
每个顶点：x, y, z
stride：3 * sizeof(GLfloat)
只有 location 0
```

11.11 当前上传版本：

``` text
每个顶点：x, y, z, r, g, b
stride：6 * sizeof(GLfloat)
location 0：position，3 个分量，offset 0
location 1：color，3 个分量，offset 3 * sizeof(GLfloat)
```

因此，原 `9.glVertexAttribPointer参数拆解.md`
需要补充第二个属性的案例，不能把旧版 stride=3
说成所有顶点数组都固定使用的值。

## 5. 当前已收到的房子作业要求

根据用户转述的老师要求：

1.  使用最新课堂代码新建项目。
2.  删除注释掉的旧代码。
3.  绘制一个房子：上方为彩色三角形（课堂绘制内容），下方为红色正方形。
4.  使用 `Shader` 类，即使用 `shader.h`。
5.  环境配置方式与课堂一致。
6.  代码要求与课堂一致，不擅自改动，不增加不需要的函数。
7.  原课堂项目必须保留，用作课堂小测试。
8.  后续检查时会进行现场编程测试，考查从第一节课到目前为止的能力。

如果老师之后发出正式书面要求或补充细节，以老师的正式文件为准。

## 6. 作业实现前必须确认、不能提前假设的事项

-   是否要求所有图形共用一个 VAO/VBO。
-   是否要求一次 `glDrawArrays()` 完成全部图形，还是分开绘制。
-   屋顶三角形的具体顶点坐标及颜色是否由老师指定。
-   正方形的具体坐标、颜色表示方式。
-   是否有指定的窗口标题、文件目录、命名或提交截图要求。

### 可用于理解的几何推导

若沿用 `GL_TRIANGLES` 且不使用索引绘制：

-   三角形需要 3 个顶点。
-   正方形可拆为 2 个三角形，需要 6 个顶点。
-   两者合计 9 个顶点。

这是图元组织的推导，不代表老师已经指定必须采用一次 9 顶点绘制。
