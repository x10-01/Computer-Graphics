## 1. 必须修正：`glfwTerminate()` 的位置

原笔记的窗口创建代码附近曾出现：

``` cpp
if (!window)
{
    glfwTerminate();
    return -1;
}
glfwTerminate(); // 这条若位于 if 外，会在正常初始化后立即终止 GLFW
```

正确的课堂逻辑应为：

``` cpp
if (!window)
{
    glfwTerminate();
    return -1;
}
```

程序正常运行时，`glfwTerminate()` 应在 Render Loop
结束之后执行，而不是在窗口创建成功后立即执行。

正确的整体顺序：

``` text
glfwInit
→ glfwWindowHint
→ glfwCreateWindow
→ 检查 window
→ glfwMakeContextCurrent
→ glewInit
→ 创建顶点数据 / Shader
→ Render Loop
→ glfwTerminate
```

## 2. 初始化顺序的因果关系

1.  `glfwInit()`：初始化 GLFW。
2.  `glfwWindowHint()`：在创建窗口前设置 OpenGL 版本和 Profile 要求。
3.  `glfwCreateWindow()`：创建窗口及其 OpenGL Context。
4.  检查窗口是否创建成功；失败时清理 GLFW 并退出。
5.  `glfwMakeContextCurrent(window)`：把窗口对应的 Context 设为当前
    Context。
6.  `glewInit()`：在当前 OpenGL Context 已建立的前提下初始化 GLEW。
7.  成功后再调用依赖 OpenGL 函数的操作，例如 VAO、VBO 和 Shader 创建。
8.  进入 Render Loop。
9.  循环结束后调用 `glfwTerminate()`。

## 3. Render Loop 的顺序与职责

``` text
while (!glfwWindowShouldClose(window))
{
    SetViewport(window);
    glClearColor(...);
    glClear(GL_COLOR_BUFFER_BIT);
    RenderObject(...);
    glfwSwapBuffers(window);
    glfwPollEvents();
}
```

  -----------------------------------------------------------------------
  调用                                职责
  ----------------------------------- -----------------------------------
  `glfwWindowShouldClose(window)`     判断窗口是否应关闭

  `SetViewport(window)`               根据 framebuffer 尺寸设置视口（后续
                                      10.9 详细记录）

  `glClearColor()`                    设置颜色缓冲区清理时使用的颜色

  `glClear(GL_COLOR_BUFFER_BIT)`      真正清理颜色缓冲区

  `RenderObject(...)`                 执行对象绘制

  `glfwSwapBuffers(window)`           交换前后缓冲区，显示准备好的画面

  `glfwPollEvents()`                  处理窗口事件
  -----------------------------------------------------------------------

`glClearColor()` 与 `glClear()` 不能混为一谈；`glfwSwapBuffers()` 与
`glfwPollEvents()` 也不是同一个功能。

## 4. RGBA 数值

-   RGBA 四个通道分别为 Red、Green、Blue、Alpha。
-   常见 8-bit 表示范围是 0--255。
-   当前 `glClearColor()` 使用归一化浮点值 0.0--1.0。
-   换算关系：归一化值 = 8-bit 通道值 / 255.0。
-   `glClearColor(0.2f, 0.3f, 0.3f, 1.0f)`
    设置背景清理颜色；它不决定三角形自身的颜色。

## 5. Shader 流程的知识边界

9.18 记录的是：

``` text
Vertex Shader
→ Rasterization
→ Fragment Shader
```

-   Vertex Shader：处理顶点输入，输出 `gl_Position` 等结果。
-   Rasterization：根据图元覆盖区域产生片段。
-   Fragment Shader：处理片段并输出颜色。
-   C++ 端负责组织数据和调用 OpenGL API；GLSL 是 Shader 源码使用的语言。

9.18 阶段的源码把 Shader 代码写成 C++ 字符串；10.9 进一步完成 Shader
创建、编译、Program 链接和顶点数据管理；11 月 6 日再改为 Shader 类和外部
Shader 文件。
