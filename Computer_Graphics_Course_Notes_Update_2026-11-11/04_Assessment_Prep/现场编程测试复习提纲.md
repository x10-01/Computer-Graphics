## 2. GLFW、OpenGL Context 与 GLEW

必须能不看笔记说出顺序：

``` text
glfwInit
→ glfwWindowHint
→ glfwCreateWindow
→ 检查 window
→ glfwMakeContextCurrent
→ glewInit
```

重点解释：

-   为什么 `glfwWindowHint()` 在创建窗口之前。
-   为什么 `glfwMakeContextCurrent()` 必须在 `glewInit()` 之前。
-   窗口创建失败为什么要 `glfwTerminate()`。
-   GLEW 初始化失败时程序为什么不能继续调用后续 OpenGL 功能。

## 5. Shader 编译、链接与 Shader 类

掌握旧版底层流程：

``` text
glCreateShader
→ glShaderSource
→ glCompileShader
→ glGetShaderiv(GL_COMPILE_STATUS)
→ glGetShaderInfoLog（失败时）
→ glAttachShader
→ glLinkProgram
→ glGetProgramiv(GL_LINK_STATUS)
→ glGetProgramInfoLog（失败时）
```

掌握 11.6 的封装：

-   `Shader` 构造函数读取两个文件并创建、编译、链接 Program。
-   `UseProgram()` 内部调用 `glUseProgram()`。
-   `RenderObject()` 接收 `Shader&`。
-   析构函数调用 `glDeleteProgram()`。
-   能解释为什么 Shader 创建和链接放在 Render Loop 之前。

## 6. VAO、VBO 与顶点属性

必须理解：

-   VBO 保存实际顶点数据。
-   VAO 保存顶点属性读取配置。
-   `glGenVertexArrays()`、`glGenBuffers()`。
-   `glBindVertexArray()`、`glBindBuffer()`。
-   `glBufferData()`。
-   `glVertexAttribPointer()` 六个参数。
-   `glEnableVertexAttribArray()`。
-   `glBindBuffer(..., 0)` 与 `glBindVertexArray(0)`。

### 旧版位置数据

``` text
x0, y0, z0, x1, y1, z1, x2, y2, z2
```

-   stride = `3 * sizeof(GLfloat)`
-   position offset = `0`

### 当前位置 + 颜色数据

``` text
x0,y0,z0,r0,g0,b0,
x1,y1,z1,r1,g1,b1,
x2,y2,z2,r2,g2,b2
```

-   stride = `6 * sizeof(GLfloat)`
-   location 0：3 个分量，offset 0。
-   location 1：3 个分量，offset `3 * sizeof(GLfloat)`。

## 7. 图元与绘制命令

掌握：

``` cpp
glDrawArrays(GL_TRIANGLES, 0, 3);
```

-   第一个参数：图元类型。
-   第二个参数：从哪个顶点开始。
-   第三个参数：读取多少个顶点。

如果使用 `GL_TRIANGLES`：

-   每 3 个顶点构成一个三角形。
-   一个正方形可拆成两个三角形。
-   若不使用索引绘制，正方形需要 6 个顶点。

## 8. 常见错误分类与排查顺序

  现象                  优先排查
  --------------------- -------------------------------------------------
  找不到 `GL/glew.h`    Include 路径、项目属性、相对目录
  链接失败              Lib 目录、Additional Dependencies、平台 x64
  找不到 DLL            Debug 环境 PATH、DLL 位置
  Shader 文件无法读取   工作目录、`res/shaders` 相对路径、文件名
  Shader 编译失败       Shader 源码、`glGetShaderInfoLog()`
  Program 链接失败      VS/FS 接口、`glGetProgramInfoLog()`
  运行时看不到图形      Context、VAO/VBO、属性索引、顶点数、Shader 输出
  不能启动 exe          先确认生成是否成功，再检查启动项目与输出路径

排查原则：先找最早出现的错误，不要在编译已经失败时先去改调试器配置。
