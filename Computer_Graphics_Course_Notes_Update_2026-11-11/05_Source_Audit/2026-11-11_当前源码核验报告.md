## 2. main.cpp 核验

### 2.1 头文件顺序

当前：

``` cpp
#include<gl/glew.h>
#include <GLFW/glfw3.h>
#include <iostream>
#include "shader.h"
```

GLEW 在 GLFW 前；`iostream` 在 `shader.h` 前。当前 `shader.h` 使用了
GLEW 类型和 `std::cout`，所以它依赖当前包含顺序。

### 2.2 顶点数据

当前数组共 18 个 `GLfloat`：

-   3 个顶点。
-   每个顶点 6 个分量。
-   3 个位置分量 + 3 个颜色分量。

### 2.3 VAO/VBO 属性配置

当前 `CreateVertexBuffer()`：

-   生成一个 VAO 和一个 VBO。
-   绑定 VAO 和 VBO。
-   将整个 `vertices[]` 上传到 `GL_ARRAY_BUFFER`。
-   配置 location 0：size 3、stride 6 个 float、offset 0。
-   启用 location 0。
-   配置 location 1：size 3、stride 6 个 float、offset 3 个 float。
-   启用 location 1。
-   解除 VBO 和 VAO 绑定。

从数据布局看，两个属性的 stride 与 offset 相互匹配。

### 2.4 RenderObject

当前签名：

``` cpp
static void RenderObject(Shader &shader, GLuint &vao)
```

当前执行：

-   `shader.UseProgram()`

-   `glDrawArrays(GL_TRIANGLES, 0, 3)`

因此当前绘制命令只读取 3 个顶点，仍然是一个三角形，不是房子。

这与 11 月 6 日课堂截图中 Shader 对象在循环前创建的结构相符。

## 3. shader.h 核验

已确认：

-   `Shader` 构造函数创建 Program。
-   构造函数调用 `CompileShaderFromFile()` 两次，分别指定 Vertex 与
    Fragment 类型。
-   `CompileShaderFromFile()` 通过 `ifstream` 与 `stringstream`
    读取文件。
-   调用 `glCreateShader()`、`glShaderSource()`、`glCompileShader()`。
-   查询 `GL_COMPILE_STATUS`。
-   编译失败时使用 `glGetShaderInfoLog()`。
-   成功后 `glAttachShader()`，然后 `glDeleteShader()`。
-   `LinkShaderProgram()` 调用 `glLinkProgram()` 并检查
    `GL_LINK_STATUS`。
-   Windows 条件编译分支中调用 `glValidateProgram()`。
-   `UseProgram()` 调用 `glUseProgram()`。
-   析构函数调用 `glDeleteProgram()`。

### 3.1 待确认的源码细节

1.  当前文件在 `LinkShaderProgram()` 中出现两次 `glLinkProgram()`
    和两次链接状态检查。
2.  文件打开失败的 catch 只打印错误，后续仍继续编译。
3.  `shader.h` 没有自身包含所有被使用的头文件，依赖 `main.cpp`
    的包含顺序。
4.  `Shader` 对象的析构函数可能在 `glfwTerminate()`
    之后执行，资源释放时机值得核对。

以上均为当前上传源码的审查发现，不是擅自修改课堂代码的理由。若老师提供的完整版本确实如此，作业仍应先按老师明确要求执行；如要修正，应先确认。

## 4. core.vs 核验

当前保存文件：

``` glsl
#version 330 core
layout (location = 0) in vec3 position;
layout (location = 1) in vec3 color;
void main()
{
    gl_Position = vec4(position, 1.0f);
}
```

已声明两个输入变量，但 `main()` 中只使用 `position`，没有将 `color`
传递给后续 Shader 阶段。

## 6. 关键结论

  环节                                            当前状态

  VBO 上传位置与颜色数据                          已配置

**结论：当前上传文件完成了顶点颜色数据准备与属性输入配置，但没有完成颜色从
Vertex Shader 到 Fragment Shader
的传递。因此，不能把当前保存文件描述为已经完成彩色三角形。**
